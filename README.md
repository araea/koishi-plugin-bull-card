# koishi-plugin-bull-card

斗牛纸牌游戏，支持娱乐与金币两种模式

## 安装

```sh
yarn add koishi-plugin-bull-card
```

在 Koishi 配置中启用，并提供 database 服务；金币模式还需要 monetary 服务。

## 指令

群聊与私聊均可用。发送 `bull.来一局` 发起，等待期间加入：娱乐模式发暗号，金币模式发下注金额。

| 指令 | 说明 |
| --- | --- |
| `bull` | 帮助 |
| `bull.来一局` | 发起一局 |
| `bull.排行榜 [数量]` | 排行榜 |
| `bull.强制结束` | 结束当前游戏，权限 2 |

每人五张牌。J、Q、K 计 10 点，A 计 1 点；任取三张凑成 10 的倍数后，余数为牛几，牛牛为 10 点，凑不出称为没牛。四炸、五花牛、五小牛为特殊牌型。

金币模式赔率：五小牛、五花牛、四炸 ×4，牛牛 ×3，牛七至牛九 ×2，其余 ×1。
