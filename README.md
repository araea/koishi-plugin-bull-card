# 斗牛

Koishi 斗牛牌局插件，支持娱乐模式和货币下注模式。

## 安装

```sh
yarn add koishi-plugin-bull-card
```

在 Koishi 中启用，并安装 `database` 服务。货币模式还需要 `monetary` 服务。

## 指令

群聊和私聊均可使用。发送 `bull.来一局` 开局，其他玩家在招募期间发送 `bull.加入 [金额]` 入座。娱乐模式也可直接发送暗号；货币模式需提供下注金额。

| 指令 | 说明 |
| --- | --- |
| `bull` | 查看帮助 |
| `bull.来一局` | 发起牌局 |
| `bull.加入 [金额]` | 加入牌局 |
| `bull.排行榜 [数量]` | 查看排行榜 |
| `bull.结束` | 重置本频道牌局；限发起者或权限 2 |

每人发五张牌。J、Q、K 计 10 点，A 计 1 点；任取三张凑成 10 的倍数后，余数为牛几，10 点为牛牛，无法凑成则为没牛。四炸、五花牛和五小牛为特殊牌型。

货币模式赔率：五小牛、五花牛、四炸为 4 倍，牛牛为 3 倍，牛七至牛九为 2 倍，其余为 1 倍。
